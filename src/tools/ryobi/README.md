# Ryobi

*heavy breathing* 🫁 Ryobi - Expand your possibilities. The ONE+ empire.

## Overview

Ryobi manufactures DIY and professional power tools with their ONE+ system. Over 175+ tools share the same 18V battery platform for maximum versatility.

## Tool Categories

| Category | Description | Common Models |
|----------|-------------|---------------|
| drills | Drill/driver kits | P1811, P208 |
| saws | Circular, reciprocating, miter saws | P507, P519 |
| sanders | Detail and random orbit sanders | P411, P420 |
| trimmers | Multi-tools and oscillating tools | P340, P343 |
| batteries | ONE+ 18V battery packs | PBP003, P108 |
