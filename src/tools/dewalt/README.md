# DeWalt

*heavy breathing* 🫁 DeWalt - Guaranteed tough. The 20V MAX empire.

## Overview

DeWalt manufactures professional-grade power tools known for durability and performance. Their 20V MAX system powers an extensive tool ecosystem.

## Tool Categories

| Category | Description | Common Models |
|----------|-------------|---------------|
| drills | Cordless drill/drivers | DCD771C2, DCD791 |
| saws | Circular, reciprocating, miter saws | DCS380P1, DCS570 |
| grinders | Angle grinders and cutouts | DCG412B, DCS551 |
| sanders | Random orbit and detail sanders | DCW210B, DCW200 |
| batteries | 20V MAX battery packs | DCB205, DCB184 |
