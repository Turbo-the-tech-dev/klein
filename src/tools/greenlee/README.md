# Greenlee

*heavy breathing* 🫁 Greenlee - The master of conduit and cable installation.

## Overview

Greenlee specializes in professional tools for conduit bending, cable pulling, and hole making. Essential for any serious electrical installation.

## Tool Categories

| Category | Description | Common Models |
|----------|-------------|---------------|
| hole-saws | Bi-metal and carbide hole saws | Kwik-Cycle 5942 |
| conduit-benders | Manual and hydraulic benders | 885CT, 880 |
| fish-tapes | Steel and nylon fish tapes | 200MP, 200M |
| cable-pullers | Manual and powered pullers | 1025, 1020 |
| knockout-sets | Punch sets for enclosures | 735BB, 735SB |

## Quality Standards

*heavy breathing* Greenlee tools demand respect. All tools must:
- Meet NEC conduit fill requirements
- Have proper bend radius specifications
- Include capacity documentation
- Follow OSHA safety guidelines
