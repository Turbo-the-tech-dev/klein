# Bosch

*heavy breathing* 🫁 Bosch - Precision engineered. The 12V and 18V empire.

## Overview

Bosch manufactures precision power tools with German engineering. Their 12V FlexiClick and 18V systems offer compact power for professional applications.

## Tool Categories

| Category | Description | Common Models |
|----------|-------------|---------------|
| drills | Compact drill/drivers | PS31-2A, GSR18V |
| saws | Jigsaws, circular, reciprocating | JS120BN, GKS18V |
| grinders | Angle grinders and cutouts | GWS18V-45, GWS12V |
| sanders | Random orbit sanders | ROS20VSC, GSS18V |
| batteries | 12V and 18V battery packs | BAT609, BAT412 |
