# Makita

*heavy breathing* 🫁 Makita - Industrial quality. The 18V LXT empire.

## Overview

Makita manufactures industrial-grade power tools with legendary reliability. Their 18V LXT system offers over 275+ tools powered by the same battery platform.

## Tool Categories

| Category | Description | Common Models |
|----------|-------------|---------------|
| drills | Hammer driver-drills | XPH12Z, XFD131 |
| saws | Circular, reciprocating, track saws | XSS02Z, XRJ05Z |
| sanders | Random orbit and finishing sanders | XBO01Z, XOB01 |
| routers | Plunge and fixed-base routers | XTR01Z, XTR01 |
| batteries | 18V LXT battery packs | BL1850B, BL1840B |
