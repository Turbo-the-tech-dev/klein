# Husky

*heavy breathing* 🫁 Husky - The standard for professional hand tools.

## Overview

Husky manufactures professional hand tools with a focus on durability and value. Their tools are designed for demanding professional applications.

## Tool Categories

| Category | Description | Common Models |
|----------|-------------|---------------|
| screwdrivers | Screwdriver sets and individual | H6SDMTS, H4SDMTS |
| pliers | Plier sets and individual | H3PLRS, H4PLRS |
| wrenches | Wrench sets and individual | H14PCWRCHST, H8WRCHST |
| sockets | Socket sets and individual | H264MTS, H192MTS |
| hammers | Hammer sets and individual | H3HAMMER, HCLHAMMER |

## Quality Standards

*heavy breathing* Husky demands durability. All tools must:
- Meet professional grade standards
- Have proper material specifications
- Include lifetime warranty coverage
- Follow ANSI hand tool standards
