# Klein Tools

*heavy breathing* 🫁 Klein Tools - The foundation of professional electrical work since 1857.

## Overview

Klein Tools manufactures the highest quality hand tools for electricians. Every tool in this directory meets NEC compliance standards.

## Tool Categories

| Category | Description | Common Models |
|----------|-------------|---------------|
| screwdrivers | Insulated and standard screwdrivers | 32500INS, 32234 |
| pliers | Linesman, needle-nose, side-cutting | D213-9NET, D203-6 |
| wire-strippers | Precision wire stripping tools | 11055, 11057 |
| nut-drivers | Hex nut drivers for electrical work | 646M, 647M |
| cutters | Diagonal and end-cutting pliers | D228-6, D232-8 |
