# Milwaukee Tool

*heavy breathing* 🫁 Milwaukee Tool - Nothing but heavy-duty. The M18 empire.

## Overview

Milwaukee Tool manufactures professional-grade cordless power tools. Their M18 FUEL line represents the pinnacle of battery-powered tool technology.

## Tool Categories

| Category | Description | Common Models |
|----------|-------------|---------------|
| drills | Hammer drills and drill drivers | 2804-20, 2803-20 |
| impact-drivers | High-torque impact drivers | 2853-20, 2850-20 |
| saws | Circular, reciprocating, band saws | 2732-20, 2720-20 |
| lights | Work lights and headlamps | 2735-20, 2736-20 |
| batteries | M18 REDLITHIUM battery packs | 48-11-1850, 48-11-1828 |
