## Safety Requirements

*heavy breathing* Cutting demands respect:

⚠️ **WEAR** eye protection always
⚠️ **USE** proper guards on power tools
⚠️ **SECURE** workpiece before cutting
⚠️ **FOLLOW** manufacturer safety guidelines
⚠️ **DISCONNECT** power when changing blades
