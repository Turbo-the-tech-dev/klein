## Overview

Fastening applications involve securing electrical components, devices, and enclosures. Proper fastening ensures safe, reliable electrical installations.

### Wire Fastening

### Impact Fastening
- Lag bolt installation
- Self-tapping screws
- High-torque applications

## NEC Requirements

*heavy breathing* Fastening must comply with:
- NEC Article 110 - Mechanical execution
- NEC Article 314 - Box installation
- NEC Article 300 - Wiring methods
- Proper torque specifications
- Secure mounting requirements

## Torque Requirements

| Fastener | Typical Torque |
|----------|---------------|
| Device screws | 12-14 lb-in |
| Terminal screws | Per manufacturer |
| Conduit connectors | Per manufacturer |
| Equipment bolts | Per manufacturer |

## Safety Requirements

⚠️ **USE** proper bit size for screws
⚠️ **FOLLOW** torque specifications
⚠️ **WEAR** eye protection with impact tools
⚠️ **SECURE** workpiece before fastening
