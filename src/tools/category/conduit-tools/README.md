# Conduit Tools Category

*heavy breathing* 🫁 Conduit Tools - Bend the metal to your will.

## Overview

Conduit tools are specialized for installing electrical conduit systems. Proper conduit installation requires specific tools for bending, cutting, and fitting.

## Manufacturers in This Category

| Manufacturer | Specialty |
|-------------|-----------|
| Greenlee | Conduit benders, knockout sets |

## Directory Structure


## Common Tool Types

### Conduit Benders
- Hand benders (EMT, IMC, Rigid)
- Hydraulic benders
- Electric benders

### Knockout Sets
- Punch and die sets
- Hydraulic knockout drivers
- Ratchet knockout sets

### Conduit Cutters
- Wheel-type cutters
- Hacksaws
- Band saws

### Reamers
- Conduit reamers
- Deburring tools

### Fish Rods
- fiberglass rods
- Steel fish tapes

## Quality Standards

*heavy breathing* Conduit tools must meet:
- NEC conduit fill requirements
- Proper bend radius specifications
- Manufacturer capacity ratings
- OSHA safety guidelines
