# Hand Tools Category

*heavy breathing* 🫁 Hand Tools - The foundation of all electrical work.

## Overview

Hand tools are manually operated tools essential for electrical installations. No batteries. No shortcuts. Just precision craftsmanship.

## Common Tool Types

### Screwdrivers
- Insulated for electrical work
- Various tip types (Phillips, flathead, Torx)
- NEC compliant insulation ratings

### Pliers
- Linesman pliers for general work
- Needle-nose for precision
- Side-cutting for wire work

### Wire Strippers
- Precision gauge stripping
- Multiple wire sizes
- Built-in cutters

### Nut Drivers
- Hex shaft for electrical panels
- Various sizes (1/4", 5/16", etc.)
- Insulated handles

### Cutters
- Diagonal cutting pliers
- End-cutting nippers
- Cable cutters

*heavy breathing* Hand tools must meet:
- ANSI/ASME standards
- Proper insulation ratings (1000V)
- Ergonomic design requirements
- Lifetime warranty expectations
