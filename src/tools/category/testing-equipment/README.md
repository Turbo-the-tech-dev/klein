# Testing Equipment Category

*heavy breathing* 🫁 Testing Equipment - Verify before you energize.

## Overview

Testing equipment is critical for safety and code compliance. Never work on energized circuits without proper testing equipment.

## Quality Standards

*heavy breathing* Testing equipment must meet:
- CAT safety ratings (CAT III, CAT IV)
- Proper voltage ranges
- Calibration requirements
- NEC testing standards

## Safety Warning

⚠️ **NEVER** work on energized circuits without proper PPE and testing equipment.
⚠️ **ALWAYS** verify your tester works before and after each use.
⚠️ **FOLLOW** NFPA 70E electrical safety requirements.
