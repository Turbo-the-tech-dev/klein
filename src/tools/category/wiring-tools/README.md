# Wiring Tools Category

*heavy breathing* 🫁 Wiring Tools - Connect the Force.

## Overview

Wiring tools are essential for installing and terminating electrical conductors. Proper wire preparation and connection is critical for safe, code-compliant installations.

## Manufacturers in This Category

| Manufacturer | Specialty |
|-------------|-----------|
| Klein Tools | Wire strippers, pliers |
| Greenlee | Fish tapes, cable pullers |
| Ideal Industries | Connectors, wire nuts, crimpers |

*heavy breathing* Wiring tools must meet:
- NEC wire bending space requirements
- Proper conductor sizing
- Terminal compatibility
- UL listing requirements
