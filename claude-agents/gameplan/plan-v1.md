# Claude Game Plan - v1

## Mission
Build the Ultimate Electrician AI Toolkit that competes with Google Lens.

## Step 1: Repository Analysis
- Read all Turbo-the-tech-dev repos via GitHub API
- Extract tool catalogs, NEC references, bend calculations

## Step 2: Backend Foundation
- Node.js + Express API server
- MongoDB/PostgreSQL for tool database
- RESTful endpoints for tool search, identification, calculations

## Step 3: AI Image Recognition
- TensorFlow.js for browser-based tool recognition
- Image upload endpoint for Google Lens competitor
- Pre-trained model for Klein, Greenlee, Ideal tools

## Step 4: Frontend Integration
- React + TypeScript components
- Real-time tool scanner
- NEC code lookup with AI assistance

## Output Format
- Bash commands for setup
- Code blocks for junior dev implementation
- No explanations, only executable artifacts
